Leather Laundry WordPress Theme
===============================

Installation:
1. Zip this folder.
2. Upload in WordPress: Appearance > Themes > Add New > Upload Theme.
3. Activate the theme.
4. Add your content:
   - Services: Custom post type "Services"
   - Cities: Custom post type "Cities"
   - Testimonials: Custom post type "Testimonials"
   - Transformations: Custom post type "Before / After"
   - FAQs: Custom post type "FAQs"
   - Blog posts: regular Posts
5. Assign menus:
   - Primary Menu
   - Services Menu
   - Cities Menu
   - Footer Menu

Brand styling:
- Fonts: Playfair Display + DM Sans
- Palette: espresso / cognac / gold / cream inspired by the uploaded mockup

Note:
If your permalink settings are new, save them once after activation.
